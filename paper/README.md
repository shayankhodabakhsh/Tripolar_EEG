# Sensors (MDPI) draft — three-way TCRE comparison

This folder holds the manuscript and supplement for the methods-harmonized
comparison of Felt vs Gel vs Paste TCRE constructions, targeted at MDPI
*Sensors*. The repo is a self-contained build: figures live in `figs/`,
auto-generated stats live in `auto_stats.md` / `felt_vep_table.md` /
`sensitivity_abc.md`, and section ownership is tracked in
`SUBMISSION_CHECKLIST.md`.

## Files

- `main.tex` — manuscript (compiles to a 15-page PDF in preview mode).
- `supplement.tex` — supplement (compiles to an 8-page PDF).
- `refs.bib` — bibliography.
- `figs/` — camera-ready figures, mirrored from `output/` by the
  build scripts.
- `auto_stats.{md,json}`, `felt_vep_table.{md,json}`, `sensitivity_abc.{md,json}`
  — auto-generated by the scripts in `../scripts/`.
- `SUBMISSION_CHECKLIST.md` — outstanding items blocking submission.

## Get the MDPI Sensors template (for the submission build)

`main.tex` is wrapped in a `\previewtrue` / `\previewfalse` toggle. In
preview mode (the default) it compiles without the official MDPI Sensors
template against vanilla TeX Live. To produce a submission-ready PDF:

1. Go to <https://www.mdpi.com/authors/latex> and download the *Sensors*
   LaTeX template ZIP.
2. Copy the `Definitions/` folder from the ZIP into this folder
   (`paper/Definitions/`).
3. Flip `\previewtrue` to `\previewfalse` at the top of both `main.tex`
   and `supplement.tex`.

Final folder layout for submission:

```
paper/
├── Definitions/
│   ├── mdpi.cls
│   ├── mdpi.bst
│   └── (cfg + logo files)
├── main.tex
├── supplement.tex
├── refs.bib
├── figs/
└── README.md
```

## Build

From the repo root, with the package installed (`pip install -e .` from
the parent dir):

```bash
python scripts/build_paper_stats.py        # refresh §3 numbers + comparison figures
python scripts/build_felt_vep_figure.py    # refresh §3.7 felt VEP
python scripts/build_sensitivity_figure.py # refresh supplement §S1 sensitivity

cd paper
pdflatex main && bibtex main && pdflatex main && pdflatex main
pdflatex supplement && pdflatex supplement
```
