# GUI Validation Report

## Current status

**Software verification is complete for the included automated tests; scientific validation is incomplete.** The GUI must not be treated as a validated clinical or autonomous rejection system. No manual rejection mask has been frozen or applied, and no GUI-derived result has been added to the manuscript.

Preparation on 26 August 2026 found 16 continuous BrainVision recordings, 12 blinded in-scope 11-channel/common-protocol records, three integrity-only records with unresolved 9-channel mapping, and one integrity-only record without the common resting protocol. It generated 672 channel-rule rows. Raw data were not modified, and no review decision was created.

Preparation also generated 16 blinded per-session `mne.Report` HTML files. Pre-freeze reports omit MNE's raw-file summary to avoid leaking source filenames; post-freeze reports add the preserved MNE recording summary and raw pre-notch PSD.

## Implemented separation and safeguards

- `mne_backend.py` uses `mne.io.read_raw_brainvision()` as the authoritative loader and preserves MNE metadata, annotations, channel names, sampling rate, and numeric events.
- `data_integrity.py` handles low-level hashes, linked-file checks, blinding, duplicates, and exact integer rails only.
- `qc_engine.py` handles deterministic technical metrics from MNE-loaded signals and uses MNE Welch/filter functions.
- `vep_analysis.py` handles post-freeze VEP/peak/alpha calculations from MNE epochs and MNE spectral estimates.
- `export_reports.py` handles append-only decisions, completeness checks, immutable freeze snapshots, and reports.
- `post_review.py` refuses to run before a hash-verified freeze or while a site remains `UNCERTAIN`.
- `notebook_review.py` and `MNE_QC_REVIEW.ipynb` provide a second blinded presentation layer over the same MNE modules and append-only CSV exports; they contain no independent signal-processing implementation.
- BrainVision files are loaded read-only through MNE; filtering creates a separate MNE `Raw` copy.
- Holder configuration, VEP SNR, alpha results, spectral correlations, and averaged morphology are locked during technical review.
- Paired post-review analysis uses the intersection of frozen tEEG/eEEG `KEEP` masks.
- 60-Hz/harmonic measurements use raw pre-notch/pre-low-pass samples; VEP and alpha use the 0.5–30-Hz branch.
- Every decision is appended with a revision ID; earlier rows are never silently overwritten.

## Synthetic artifact validation completed

Unit tests inject and detect clipping plateaus, flatlines, 60-Hz sinusoidal contamination, baseline steps, and event incompleteness. The educational page additionally generates clearly labeled synthetic examples of clipping, flatline, pops, 60-Hz interference, slow drift, and muscle-like bursts. Synthetic samples are created in memory and never enter project analysis.

## Validation still required before scientific use

1. An experienced EEG researcher must independently label a prespecified subset of clean and contaminated raw intervals and all artifact classes.
2. Compare detector sensitivity, specificity, positive predictive value, and interval overlap against those labels, with confidence intervals.
3. Have a second reviewer independently assess a blinded subset; report agreement for site categories and epoch decisions.
4. Inject synthetic clipping, flatlines, line noise, drift, pops, muscle bursts, and mixed artifacts across amplitudes/durations into held-out clean project segments; measure detection curves.
5. Repeat results over documented threshold grids and 0.5–30, 1–20, and 0.5–20-Hz VEP branches. Do not select a setting based on favorable physiological outcomes.
6. Verify peak-detection windows and terminology with the actual checkerboard protocol, display parameters, eye condition, and an EEG/VEP domain expert.
7. Independently reproduce frozen-mask results with separate code and compare every site/trial denominator and scalar output.
8. Test the Streamlit workflow with a novice reviewer: opening a record, jumping to warnings, completing all decisions, correcting a revision, freezing, exporting, and recovering from interruption.
9. Validate HTML/PDF reports visually across all sessions.

Until these steps are complete, thresholds are provisional technical screens. The 5% continuous clipping rule is retained only for historical compatibility and is not accepted as a stand-alone scientifically justified criterion.
