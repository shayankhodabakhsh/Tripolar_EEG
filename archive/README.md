# Archive

Material kept for provenance but not on the active analysis path. Nothing
in this folder is imported by the package, the scripts, or the paper.

## Contents

- **`my_report/`** — early weekly progress reports and intermediate
  manuscript drafts (LaTeX sources for the SK1 single-subject report
  and three-way comparison drafts pre-MDPI).
- **`Figures_per_subject_summary/`** — per-subject single-subject
  summary figures generated by an earlier version of the pipeline;
  superseded by figures in `output/`.
- **`ELE573_class_project/`** — class-project material, kept for
  reference; not part of the manuscript.
- **`single_subject_analysis.ipynb`** — earlier version of the
  single-subject notebook; current version is
  `notebooks/single_subject_analysis_v2.ipynb`.
- **`EEG_Decomposition_Notebook_SK1*.ipynb`** — exploratory wavelet
  decomposition notebooks; not on the analysis path.
- **`Tripolar_EEG.ipynb`** — original exploratory notebook.
- **`old_src_report.tex`** — early `report.tex` that lived in `src/`;
  preserved for diff history.
